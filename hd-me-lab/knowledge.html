03 / 樑

簡支樑中間撞度

拖動力同長度，看撞度點變。公式 δ = FL³ / (48EI)。長度影響最大（立方）。

δ 中間
—
公式
δ = FL³/(48EI)

假設 E = 200 GPa，I = 1.0×10⁵ mm⁴（約 50×50 方鋼）。只係示意，唔係設計值。

05 / 振動 · 進階

共振 — 動態放大

《機械振動》Rao。當外力頻率近固有頻率，振幅會大幅增加。拖動頻率比，看放大倍數。

06 / 疲勞

循環載荷下的壽命

《疲勞與斷裂力學》康國政。強度未超限，件仲可以斷。拖動應力幅，看預估周次（S-N 概念）。

預估周次 N
—

簡化 Basquin：N = C / σaᵇ，C=10¹⁴，b=3。只係示意趋勢，不是材料數據。

07 / 有限元 · 現代

把連續體切成小塊，再拼回

《有限單元法》王勁成 + 曾攀。軟體唔係天花板。網格太粗、邊界錯、單位錯，都會出「美麗的垃圾」。理論先於按鈕。

網格越細，近似越好，但計算量上升。關鍵位置（應力集中）先加密。

不同目標的閱讀組合
