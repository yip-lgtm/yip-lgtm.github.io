03 / 樑

簡支樑中間撞度

拖動力同長度，看撞度點變。公式 δ = FL³ / (48EI)。長度影響最大（立方）。

δ 中間
—
公式
δ = FL³/(48EI)

假設 E = 200 GPa，I = 1.0×10⁵ mm⁴（約 50×50 方鋼）。只係示意，唔係設計值。

05 / 疲勞

循環載荷下的壽命

強度未超限，件仲可以斷。拖動應力幅，看預估周次（S-N 概念）。

預估周次 N
—

簡化 Basquin：N = C / σaᵇ，C=10¹⁴，b=3。只係示意趋勢，不是材料數據。

06 / 有限元

把連續體切成小塊，再拼回

軟體唔係天花板。網格太粗、邊界錯、單位錯，都會出「美麗的垃圾」。理論先於按鈕。

網格越細，近似越好，但計算量上升。關鍵位置（應力集中）先加密。

07 / 應用

不同目標的閱讀組合

目標組合解決問題
考研／本科核心機原 + 機設 + 材力基礎理論與手算
常規非標自動化手冊 + 材力 + ANSYS 實例標準件 + 簡單強度校核
高端（航天／汽車／重工）振動 + 疲勞 + 有限元 + ABAQUS共振、壽命、非線性
流體與熱能流體力學 + Anderson CFD泵閥、流道、空氣動力

數值同公式都係簡化示意，用來理解趋勢。實際設計要用材料手冊、標準同正規軟體。
