# Copper and Tellurium

銅與碲。從馬恩河走到諾曼第的可愛戰史，手機網頁版。

```bash
npm install
sh startup.sh
```

開發伺服器在 `http://127.0.0.1:8080/`。靜態頁在 `https://yip-lgtm.github.io/cute/`。
