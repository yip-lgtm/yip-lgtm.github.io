G2645 notes

a–g、剪力、彎矩、Perry–Robertson 詳解

Bilingual notes for the signed sheet. Bottom channel 127×64×14.9 and top SHS 50×50×3.2.

a. 剪力 | Shear

剪力同支撐軸力同一個數。頂部 6.90 kN，底部 17.1 kN。

Shear is the same number as the strut force. Top 6.90 kN, bottom 17.1 kN.

方管有效剪力面積：

Effective shear area of the SHS:

Av = 2 t d = 2 × 3.2 × 40.4 = 258.56 mm²

剪力屈服係 py/√3 = 0.577 py。純剪力有一拉一壓，von Mises 把佢哋合成。

Shear yield is py/√3 = 0.577 py. Pure shear is one tension and one compression; von Mises combines them.

Pv = 0.577 × 275 × 258.56 / 1000 = 41.03 kN
6.90 < 41.03，且 6.90 ≤ 0.6 × 41.03 = 24.6　低剪力 low shear, O.K.

6.90 點來：頂部土壓 14.8，圍令闊 0.45 m，跨度 1.46 m，兩端各一半，再乘 1.4。

Where 6.90 comes from: top pressure 14.8, waling width 0.45 m, span 1.46 m, each end takes half, then × 1.4.

Fvy = 14.8 × 0.45 × 1.46 / 2 × 1.4 = 6.9 kN

b. 彎矩容量 | Moment capacity

頂部 My = 2.63 × 0.45 × 1.4 = 1.65 kNm。低剪力，容量用全值。

Top My = 2.63 × 0.45 × 1.4 = 1.65 kNm. Low shear, so capacity uses the full value.

Mc = min(py S, 1.2 py Z) / 1000 = 2.84 kNm
1.65 ≤ 2.84　O.K.

印刷的 ρ = (−1 + 2Fv/Pv)² 係高剪力先用。而家低剪力，當 ρ = 1。

The printed ρ = (−1 + 2Fv/Pv)² is for high shear. Here it is low shear, so take ρ = 1.

底部同樣：4.16 ≤ 5.03。

Bottom is the same method: 4.16 ≤ 5.03.

c. 屈曲抵抗 | Buckling resistance

開口槽鋼受強軸彎，可以側向扭出。計算書假設無完全約束。但呢條彎矩係 My，Mx = 0，唔控制。

An open channel bent about the strong axis can twist sideways. The sheet assumes no full restraint. But the moment here is My and Mx = 0, so it does not govern.

方管閉口，計算書寫 No Mb check required。

For the closed SHS, the sheet says no Mb check is required.

d. 軸向壓應力 | Axial compressive stress

手算只係 fc < 275：唔會壓扁。軟件再睇長柱會唔會弓出。

The hand check is only fc < 275: it will not squash. The software then checks whether the long member bows out.

頂部方管：λ = 76.4，curve (a)，pc = 210.9，Pc = 125 kN > 6.9。

Top SHS: λ = 76.4, curve (a), pc = 210.9, Pc = 125 kN > 6.9.

底部槽鋼：λy = 77.7，curve (c)，pc = 165.8，Pc = 315 kN > 17.1。

Bottom channel: λy = 77.7, curve (c), pc = 165.8, Pc = 315 kN > 17.1.

Perry–Robertson

歐拉係完美直柱。Perry–Robertson 加一個初始彎 η，把 py 同 pE 連成一條折減曲線，得出真實可用嘅 pc。

Euler is a perfect straight column. Perry–Robertson adds an initial bow η, joins py and pE into a reduced curve, and gives the usable pc.

pE = π² E / λ²
η = a (λ − λ0) / 1000
φ = [py + (η+1) pE] / 2
pc = pE py / [φ + √(φ² − pE py)]

槽鋼用 curve (c)，a = 5.5。方管用 curve (a)，折減少啲。

The channel uses curve (c), a = 5.5. The SHS uses curve (a), which reduces less.

e. 局部容量 | Local capacity

截面本身，壓同彎一齊，未計長柱屈曲。

The cross-section itself, compression plus bending, before member buckling.

P/(Ag py) + My/Mcy

頂部：0.04 + 0.58 = 0.62 ≤ 1。底部：0.03 + 0.83 = 0.86 ≤ 1。

Top: 0.04 + 0.58 = 0.62 ≤ 1. Bottom: 0.03 + 0.83 = 0.86 ≤ 1.

f. 整體屈曲 | Overall buckling

長柱再加彎矩。軸力用 Pc，唔用 A py。

Long member plus bending. Axial force uses Pc, not A py.

P/Pc + m My/Mcy

頂部：0.06 + 0.58 = 0.64 ≤ 1。底部：0.05 + 0.83 = 0.88 ≤ 1。

Top: 0.06 + 0.58 = 0.64 ≤ 1. Bottom: 0.05 + 0.83 = 0.88 ≤ 1.

g. 拉力加彎矩 | Tension with moments

而家係壓力，T = 0。軟件仍然印出 My/Mcy。頂部 0.58，底部 0.83，都 ≤ 1。

This member is in compression, so T = 0. The software still prints My/Mcy. Top 0.58, bottom 0.83, both ≤ 1.
