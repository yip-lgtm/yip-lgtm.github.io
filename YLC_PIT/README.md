# YLC Pit Programme

Yuet Lai Court Feature 11NW-A/C16 — no-fines concrete pit-by-pit programme.

- 124 pits from the approved excavation sequence (Rows 21–24, 31–34, 41–44, 51–54, 61–64, 71–72).
- Click a pit for its own page (`#R21-1A-1`).
- Upload photos and record status / dates. Data stays in this browser (IndexedDB).
- Export / import JSON to move records between devices.
- Download an individual HTML file for any pit.

Live: https://yip-lgtm.github.io/YLC_PIT/
